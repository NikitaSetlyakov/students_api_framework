# Autotest Framework for Students API

Тестовый фреймворк для API-тестирования сервиса управления данными студентов.

## Подготовка окружения

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск тестов

Все тесты:

```bash
pytest
```

По маркерам:

```bash
pytest -m smoke        
pytest -m negative    
pytest -m positive     
pytest -m regression  
```

Отчёт Allure:

```bash
allure serve allure-results
```

При запуске `pytest` автоматически:
- Включается подробный вывод (`-v`).
- Сохраняются результаты для Allure (`--alluredir=allure-results`).
- Очищаются результаты предыдущего запуска (`--clean-alluredir`).

## Архитектура проекта

- `src/clients/` — API-клиент для работы со Students API.
- `src/utils/builders/` — формирование данных для создания и обновления студентов.
- `src/utils/helpers/` — переиспользуемые проверки данных студентов.
- `src/utils/assert_wrappers.py` — обёртки проверок с Allure-шагами.
- `tests/` — API-тесты.
- `conftest.py` — фикстуры для подготовки клиента, генерации данных и создания студентов.
- `pytest.ini` — настройки запуска, маркеров и результатов Allure.

## Тестовое покрытие

Основные сценарии:
- Создание студента с валидными данными.
- Получение студента по ID.
- Получение списка студентов.
- Обновление данных студента.
- Удаление студента.

Негативные сценарии:
- Создание студента с некорректными значениями полей.
- Создание студента без обязательных полей.
- Получение студента после удаления.
- Обновление удалённого студента.
- Повторное удаление студента.

Валидация:
- Проверка HTTP-статусов.
- Проверка структуры и типов данных ответа.
- Проверка сообщений и статусов операций.
- Сравнение полей студента с отправленными данными.
- Проверка отсутствия студента после удаления.
